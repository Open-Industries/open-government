# Domain Standards — Digital Government

Alignment mapping for this core. *Aligned to* throughout: legal validity of acts,
official identity proofing and statutory records remain governed by each adopter's
legal framework.

## Concept mapping

| Platform concept | Domain standard / framework | Mapping |
|---|---|---|
| Cases & fees | Public-administration practice | Case registry with masked folios; guarded fee accounts |
| Eligibility & processing | Program rules of the adopter | Rules context with reasoned, auditable decisions |
| Open data outputs | W3C DCAT / DCAT-AP | Transparency evaluator verdicts feed DCAT-described datasets |
| Security controls | NIST SP 800-53 + ISO 27002 | Mapped in `docs/security/` |
| Accessibility | WCAG 2.2 | Contract-level commitment for citizen-facing APIs |
| Indicators | ISO 37120 | Transparency metrics posture |

## Scope boundaries

This core does not issue legally binding resolutions, verify identity documents, or
replace official registries; it is the case/fee/rules platform agencies integrate with.
